# OpenSCAD (Undergrad College Project)

This repository contains an OpenSCAD project developed as part of an undergrad college course.

## Project Structure

The project is organized into sub-directories, each representing a different component or module.

### BezierPipe-1

This directory contains the OpenSCAD files for generating a Bezier pipe.

- `BezierPipe.scad`: The main OpenSCAD file for the Bezier pipe.
- `BezierPipe.JPG`: An image showcasing the generated Bezier pipe.

## How to View

To view and modify these OpenSCAD designs, you will need to have OpenSCAD installed on your system.

1. **Download OpenSCAD**: If you don't have OpenSCAD, you can download it from the official website: [OpenSCAD Downloads](http://www.openscad.org/downloads.html)
2. **Open the `.scad` files**: Navigate to the respective project directory (e.g., `BezierPipe-1/`) and open the `.scad` file (e.g., `BezierPipe.scad`) with OpenSCAD.
3. **Render the model**: Once opened, you can render the 3D model within OpenSCAD.
